# Super-Galactic-Giganticly-Mangificent-Majestic-Cosmic-ev-apm-agent
This project is made for the Unstop Hackathon. This is an EV Asset Performance Management (APM) Agent. This is a group project made by Dhanvi, Vidhi, Bansil and Yug.

Problem: Fleet operators struggle to monitor battery health across hundreds of EVs.

Solution: 
An AI agent continuously monitors:
* Battery State of Health (SoH)
* Charging patterns
* Temperature and thermal events
* Battery degradation trends
  
Outputs:
* Predictive maintenance alerts
* Remaining Useful Life (RUL) estimates
* Optimal charging recommendations
* Battery replacement forecasting
* 
Benefits:
* Increased battery lifespan
* Reduced downtime
* Lower maintenance costs
* Improved fleet reliability
